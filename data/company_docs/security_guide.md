# 정보보안 정책 가이드

본 문서는 회사의 정보자산을 보호하고 보안 사고를 예방하기 위한 필수 정책을 안내합니다. 모든 임직원은 본 정책을 숙지하고 준수해야 합니다.

---

## 1. 정보 보안 원칙

### 1.1 기본 원칙
- **기밀성(Confidentiality):** 인가된 사용자만 정보에 접근할 수 있어야 합니다.
- **무결성(Integrity):** 정보의 정확성과 완전성이 보장되어야 합니다.
- **가용성(Availability):** 인가된 사용자가 필요할 때 정보에 접근할 수 있어야 합니다.

### 1.2 적용 범위
- 전 임직원, 계약직, 협력업체 직원
- 회사 소유의 모든 정보자산 (문서, 시스템, 데이터베이스, 소스코드 등)
- 사내 및 재택근무 환경 모두 적용

## 2. 데이터 분류 체계

### 2.1 분류 등급

| 등급 | 명칭 | 설명 | 예시 |
|------|------|------|------|
| **1등급** | 극비(Top Secret) | 유출 시 회사 존립에 치명적 영향 | 핵심 기술, M&A 정보 |
| **2등급** | 비밀(Confidential) | 유출 시 심각한 재정적 손실 | 고객정보, 재무데이터, 소스코드 |
| **3등급** | 대외비(Internal) | 사내 공유용, 외부 유출 금지 | 내부 정책, 조직도, 급여 정보 |
| **4등급** | 공개(Public) | 외부 공개 가능 | 제품 소개서, 공식 보도자료 |

### 2.2 등급별 처리 방침

**극비/비밀 등급:**
- 암호화 필수 (AES-256 이상)
- 접근 로그 기록 및 모니터링
- 프린트 및 복사 제한
- 이메일 전송 시 DLP 시스템 통과 필수

**대외비 등급:**
- 사내 네트워크 내에서만 접근
- 외부 전송 시 관리자 승인 필요

## 3. 계정 및 접근 관리

### 3.1 비밀번호 정책
- **최소 길이:** 12자 이상
- **복잡성:** 대문자, 소문자, 숫자, 특수문자 중 3가지 이상 조합
- **변경 주기:** 90일마다 변경 필수
- **재사용 금지:** 최근 5개 비밀번호와 동일 불가
- **잠금 정책:** 5회 실패 시 30분 계정 잠금

### 3.2 다중 인증(MFA)
모든 시스템에 2단계 인증이 적용됩니다:
- 1단계: ID/비밀번호
- 2단계: OTP 또는 생체인증(지문, 얼굴)

### 3.3 접근 권한 원칙
- **최소 권한 원칙:** 업무 수행에 필요한 최소한의 권한만 부여
- **직무 분리:** 상충되는 권한은 분리하여 부여
- **정기 검토:** 분기별 접근 권한 적정성 검토

## 4. 네트워크 보안

### 4.1 사내 네트워크
- 모든 네트워크 트래픽 암호화(TLS 1.3)
- 무단 기기 접속 차단 (NAC 시스템)
- 게스트 Wi-Fi는 업무망과 완전 분리

### 4.2 원격 접속
- **VPN 필수:** 재택근무 시 회사 VPN을 통해서만 접속
- **승인된 기기만:** MDM 등록된 기기에서만 접근 가능
- **세션 타임아웃:** 30분 비활성 시 자동 로그아웃

### 4.3 금지 행위
- 개인 공유기, 핫스팟 사용 금지
- 토렌트, P2P 프로그램 사용 금지
- 승인되지 않은 클라우드 서비스 사용 금지

## 5. 물리적 보안

### 5.1 출입 통제
- **보안 구역 분류:** 일반/제한/통제 구역으로 구분
- **출입증:** 항상 패용, 타인에게 대여 금지
- **방문객:** 사전 등록 및 에스코트 필수

### 5.2 클린 데스크 정책
- 퇴근 시 책상 위 문서 정리
- 중요 문서는 시건 장치가 있는 서랍에 보관
- 화이트보드, 포스트잇 등 민감 정보 제거

### 5.3 저장매체 관리
- USB, 외장하드 사용 시 사전 승인 필요
- 회사 지급 암호화 USB만 사용 가능
- 폐기 시 완전 삭제(Wipe) 후 물리적 파쇄

3. **조사 협조:** 보안팀 조사에 적극 협조
4. **재발 방지:** 원인 분석 및 개선 조치 이행
